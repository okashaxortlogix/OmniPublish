# Optional AI Layer — Phase 5+

AI should be an assistive layer, not an autonomous publisher by default.

## Possible features
- title suggestions
- captions
- hashtag suggestions
- platform-specific rewrites
- tone selection
- short/long variants
- content summary
- translation

## Human approval
Generated content must appear as editable suggestions.

Recommended flow:
`Generate → Review → Edit → Approve → Publish`

## Safety and quality
- never fabricate claims about the video
- derive suggestions from supplied content/transcript
- preserve user-provided facts
- allow regeneration
- store model/version metadata for reproducibility
