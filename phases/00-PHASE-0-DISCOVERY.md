# Phase 0 — Discovery & API Verification

## Objective
Turn the concept into verified implementation requirements.

## Tasks
- [ ] Verify current official API documentation for every target platform.
- [ ] Verify publishing endpoints and media constraints.
- [ ] Verify OAuth flows, scopes, review requirements, and account restrictions.
- [ ] Verify scheduling support.
- [ ] Verify webhook/status mechanisms.
- [ ] Decide MVP platforms based on verified API capabilities.
- [ ] Freeze MVP requirements.
- [ ] Create platform compliance checklist.

## Deliverables
- verified platform matrix
- API references
- OAuth scope list
- final MVP PRD
- risk register

## Gate
Do not start production adapter implementation until each selected platform has verified API capability documentation.
